方法路径说明

员工接口（需要登录）

方法路径说明
GET/emps 分页 + 多条件：?name=罗&gender=男&dept=技术部&page=1&size=5
GET/emps/{id}按主键查询
GET/emps/list全量列表（不分页）
POST/emps新增，请求体为 Emp JSON
PUT/emps修改，请求体必须含 empId
DELETE/emps/{id}单条删除
DELETE/emps批量删除，请求体为 id 数组，如 [1,2]
统一返回 {"code":200,"message":"success","data":…}；未登录 401、参数/业务失败 400、服务端异常 500。
校验规则：姓名非空且 ≤50 字、薪资必填且 ≥0、性别 1 个字符、部门/岗位 ≤50 字。
